# Pre-Entrega Automation Testing - Erika Helfenstern

## 📌 Propósito del proyecto
Este proyecto corresponde a la pre‑entrega de **Automation Testing**.  
El objetivo es demostrar el uso de **Python, Pytest y Selenium WebDriver** para automatizar pruebas funcionales sobre el sitio [saucedemo.com](https://www.saucedemo.com).

## 🛠️ Tecnologías utilizadas
- **Python 3.13**
- **Pytest** como framework de testing
- **Selenium WebDriver** para automatización de navegador
- **pytest-html** para generación de reportes
- **Git y GitHub** para control de versiones


## ⚙️ Instalación de dependencias
Clonar el repositorio y ejecutar:
```bash
pip install -r requirements.txt


▶️ Ejecución de pruebas
Para correr todos los tests:

bash
pytest -v -s
Para generar un reporte HTML:

bash
pytest -v --html=reports/reporte.html --self-contained-html
